# Third-party notices

Daravel is an independent implementation in Dart. Its code is its own; it
matches Laravel and some Laravel packages in data formats and behaviour so
applications on both can share a database, a disk and clients. Where text
or closely followed logic comes from another project, that project's
license applies to it and is reproduced here.

## laravel/framework

- The default English validation messages
  (`src/Illuminate/Translation/lang/en/validation.php`, Laravel 12.x),
  reproduced in `packages/daravel/lib/src/validation/messages.dart` and
  `packages/daravel_test/lib/src/conformance/laravel_validation_messages.dart`
  (generated by `tool/conformance/sync_laravel_messages.dart`).
- Short user-facing strings kept identical for wire compatibility, such as
  the pagination labels (`&laquo; Previous`, `Next &raquo;`) and the
  validation and authentication error messages of the JSON responses.

## spatie/laravel-medialibrary and spatie/image

`packages/daravel_medialibrary` follows their behaviour so Laravel and
Daravel share media: the file name sanitizer and its list of disallowed
extensions (`FileAdder`), the file and conversion naming
(`DefaultPathGenerator`, `DefaultFileNamer`), and the image size rules of
`width()`, `height()`, `fit()` and `crop()` (`Size`, `Fit`,
`PerformsFitCrops`).

Sources: <https://github.com/spatie/laravel-medialibrary>,
<https://github.com/spatie/image>

## Formats only

Other packages implement data formats and protocols, not code, of their
counterparts, and contain no text from them: spatie/laravel-permission and
spatie/laravel-activitylog (table schemas), Laravel Sanctum (token format),
maatwebsite/excel and PhpSpreadsheet (XLSX and CSV), opcodesio/log-viewer,
LiveKit (its HTTP API and token claims) and the Google APIs. Trademarks are
listed under "License & trademarks" in README.md.
