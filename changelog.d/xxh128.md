### Added

- `Xxh128`: XXH3-128 (default secret, seed 0) in pure Dart, the same digest as PHP's `hash('xxh128', …)`, ported from xxHash v0.8.2 (BSD 2-Clause, notice kept in the source). Laravel uses it for the queue lock key of a job class that defines `displayName()` (ADR-041); tested against xxHash's own sanity vectors (lengths 0 to 4161, every length path and block boundary) and against values computed by PHP 8.2.

### Upgrade notes

- New public name `Xxh128` in `package:daravel` (an application class of that name and the barrel import give an ambiguous-import error; `hide` it or rename yours).
