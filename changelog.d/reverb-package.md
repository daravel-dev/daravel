### Added

- `daravel_reverb` (Blueprint #135, R3): the Pusher server in a process of its own, after Laravel Reverb. `withReverb()` reads `ReverbConfig` (`REVERB_SERVER_HOST/PORT/PATH/ISOLATES/AUTH`, `REVERB_HOST`, `REVERB_APPS` with the entries of Reverb's `config/reverb.php` as JSON, `REVERB_APPS_PROVIDER`, `REVERB_APPS_CACHE_TTL`; secrets never in `toMap`; checks for duplicate ids or keys, origins that are not host names, secrets under 32 bytes) and gives the server its applications (`ReverbApps.fromEnv`, `ReverbApps.database()` with `DatabaseAppProvider` and `CreateReverbAppsTable`). `dartisan reverb:start [--host] [--port] [--path] [--hostname] [--isolates] [--debug]` serves only the broadcasting routes, `/up`, `/up/ready` and `/metrics` in worker isolates; `reverb:restart` drains every isolate over `REVERB_DRAIN_SPREAD` and spawns it again; `reverb:stats [--url] [--token] [--json]` reads the server's `/metrics`. The commands are in `package:daravel_reverb/commands.dart`; `dartisan pub:add reverb`. Core hooks, additive: `Application.serveBroadcastingOnly(path:, auth:, debug:)` and `servesBroadcastingOnly`; `Application.restart()` and `restartRequested` (a supervisor worker that restarts is spawned again at once, not counted as a crash: `WorkerRestarting`); `ApplicationBuilder.withBroadcastApps(factory)` (the app provider made at boot; `withBroadcasting(apps:)` still wins); `PusherObserver.frame` and `PusherFrameLog` (frames with signatures masked); `Application.configChecks` (the checks boot runs), which `dartisan doctor` now runs too, so a package's checks (`withConfigCheck`) appear in `doctor --production`. Guide: [Broadcasting](docs/guide/broadcasting.md#a-separate-websocket-server).

### Upgrade notes

- Reverb hooks (R3): new public names `PusherFrameLog` and `WorkerRestarting` in `package:daravel` (an application class of one of these names and the barrel import give an ambiguous-import error; `hide` it or rename yours); new members `Application.serveBroadcastingOnly`, `servesBroadcastingOnly`, `restart`, `restartRequested` and `configChecks`, `ApplicationBuilder.withBroadcastApps` and `PusherObserver.frame` (an extension of yours declaring one of these names is shadowed by the member; a `PusherObserver` subclass with a `frame` of another signature no longer compiles). `dartisan doctor` also runs the queue's checks and those packages register, so it can list warnings it did not before.
